## 4. 只有你能決定的事（SOP清單）

這幾件事我不會自己動手，因為牽涉的不是「能不能做」而是「該不該做」：

### 4.1 端點偵測延遲的架構取捨 🔴 待你決定

**現況**：喚醒詞觸發到系統聽懂你講的話，實測要5.4秒（目標1.5秒）。拆解後發現大部分時間花在「確認你真的講完話了」這個安全設計上——講完話之後系統會刻意多等一段安靜時間，避免你話還沒講完就被誤判打斷（這是P1階段的踩坑經驗換來的設計）。

**你需要決定**：
- **選項A（維持現狀）**：接受目前5.4秒的延遲，優先保證不會誤切斷你的話
- **選項B（縮短等待）**：把安靜確認的等待時間調短（例如從0.8秒改成0.4秒），換取更快的回應速度，但會增加「你話還沒講完就被系統誤判成講完了」的機率
- **選項C（其他方案）**：例如改用更聰明的端點偵測方式（不是單純數安靜時間），但這是比較大的架構改動，需要重新設計跟測試

**怎麼回覆我**：直接告訴我選A/B/C，如果選B可以順便告訴我你能接受的延遲上限（例如「3秒以內都可以」），我會照你的決定去調整並重新測試驗證。

### 4.2 喚醒詞8小時誤觸發率測試 🟡 待你授權

**現況**：藍圖要求量測「連續8小時環境噪音下，喚醒詞被誤觸發幾次」，這是唯一還沒測的KPI。

**為什麼需要你授權**：這個測試需要真的讓系統無人值守跑8小時連續監聽麥克風，而且過程中L0/L1指令（像「現在幾點」這種免確認的）會自動執行——如果喚醒詞被環境噪音誤觸發，系統可能會在你不知情的情況下對電腦做出真實操作（雖然都是低風險動作，但畢竟是沒人在旁邊看著的8小時）。

**你需要決定**：
- 要不要現在就啟動這個測試？如果要，測試期間**麻煩你避免對著電腦所在的房間講太多話**（不然噪音樣本會不準），也請確認你不介意這8小時內系統可能真的執行幾個像查時間、調音量這種低風險指令
- 或者你想找一個你確定會離開電腦一段時間的時段再啟動（例如晚上睡覺時）

**怎麼回覆我**：說「現在開始測」或者給我一個你覺得合適的時間點，我會啟動測試並在完成後回報結果。

### 4.3 （低優先度，僅供參考）Xbox Game Bar螢幕錄影功能

**現況**：`record_screen`工具的程式碼邏輯是對的，但這台機器的Xbox Game Bar背景服務起不來，沒辦法真的驗證錄影檔案會產生。這不影響其他任何功能，優先度低，**不需要你現在處理**，除非你之後真的想用語音錄螢幕，到時候我們再一起排查（可能需要你手動先在Windows設定裡確認Game Bar有正常啟用過一次）。

### 4.4 （新增）P5視覺備援：VRAM架構取捨 + 下載大型模型檔案需要你同意 🔴 待你決定

**現況**：查證過P5「Vision Fallback」的軟硬體前提（技術細節見`docs/06`「P5視覺備援：軟硬體可行性查證」一節）——好消息是軟體完全支援藍圖指定的`Qwen3-VL-30B-A3B-Instruct`，現有的`llama-server.exe`不用重新編譯就能跑。但硬體有個真實限制：這台機器RTX Spark總共24.5GB顯示卡記憶體，目前常駐的文字LLM已經佔用約12.4GB，剩下約12GB裝不下這個VL模型（即使量化過，30B參數的權重預估還是要17~20GB）。

**你需要決定架構方向**（查了一下llama.cpp社群的實際做法，補充更新：方案A比原本想的更可行，不是要自己手刻一套換入換出邏輯）：
- **方案A（換入換出，推薦）**：這台機器現有的`llama-server.exe`已經內建「router模式」（`--models-dir`/`--models-max`/`--sleep-idle-seconds`這幾個參數，剛用`--help`確認真的存在，不是要另外裝軟體），本來就是設計給「多個模型共用一張顯示卡、閒置自動卸載、要用自動載入」這個情境用的，不用自己刻換入換出的邏輯。代價是每次觸發視覺備援，第一次呼叫會有幾秒到十幾秒的模型載入延遲（畢竟要從SSD讀17~20GB進顯示卡）
- **方案B（改用較小/更激進量化的VL模型）**：犧牲一些視覺理解準確度，換取跟文字LLM同時常駐、沒有載入延遲
- **方案C（CPU/部分GPU卸載VL模型）**：不搶顯示卡記憶體，但視覺理解的推論速度會慢很多

**另外，不管選哪個方案，都需要先下載模型檔案（約15~20GB）**——這是「下載檔案」這類我不會自己決定按下去的動作，需要你先同意（知道檔名/來源/大小之後）。

**怎麼回覆我**：告訴我選A/B/C（或你有其他想法），我會先去確認實際能下載的Qwen3-VL GGUF版本跟真實檔案大小，跟你確認一次再下載，下載完會實測跟你回報VRAM佔用、視覺理解準確度、延遲這幾個真實數字，不會只憑理論宣稱做到。
